# Plots

The scripts in this folder are used to generate the plots for this thesis.
Therefore, the pcaps and qlog files from QUIC Workbench simulations have to be placed in the respective folders.
Currently, the latest captures can be found here.


## Verification and Validation
To reproduce the results, just run the QUIC Interop Runner and copy the left nodes pcaps from the log folder generated by the "validation" test case.
To run the verification and validation tests on the workbench, a script can be found under `/simulation/verification-validation`.
